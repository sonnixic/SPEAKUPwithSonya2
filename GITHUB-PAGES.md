# Публикация SPEAK UP! через GitHub Pages

Проект подготовлен для https://USERNAME.github.io/speak-up/. Вместо USERNAME используется ваш логин GitHub. Имя репозитория должно быть **speak-up**.

## Загрузка через браузер — без команд

1. Распакуйте архив **speak-up-github-pages.zip**. Внутри папки `speak-up-upload` находятся только файлы для репозитория. Не загружайте ZIP как один файл и не используйте старый архив полной локальной версии.
2. На GitHub нажмите **+ → New repository**, укажите имя **speak-up**, выберите **Public**, включите **Add a README file**, нажмите **Create repository**. Основная ветка должна называться **main**.
3. Откройте **Add file → Upload files**. Перетащите содержимое папки `speak-up-upload`, а не саму эту папку: `package.json`, `index.html`, `vite.config.ts` и папка `src` должны оказаться в корне репозитория. Нажмите **Commit changes**, сохранив в **main**.
4. Проверьте, что в репозитории есть **.github/workflows/deploy-pages.yml** и **.gitignore**. Windows может скрывать их: в Проводнике включите **Вид → Показать → Скрытые элементы**. Если загрузка скрытой папки не удалась, нажмите **Add file → Create new file**, введите полный путь `.github/workflows/deploy-pages.yml`, вставьте содержимое одноимённого файла из распакованного архива и нажмите **Commit changes**. Так же можно создать `.gitignore`.
5. Перейдите в **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
6. Откройте **Actions → Deploy speak-up to GitHub Pages**. Если первая попытка до включения Pages была красной, нажмите **Run workflow → main → Run workflow**. Дождитесь зелёной отметки. Ссылка будет в **Settings → Pages**: `https://ВАШ-ЛОГИН.github.io/speak-up/`.
7. Откройте сайт, запустите урок и проверьте переключение этапов. Для последующих изменений редактируйте или загружайте файлы в **main**: Actions повторит публикацию автоматически.

Если репозиторий уже создан, используйте его, сохранив имя speak-up и ветку main. На бесплатном аккаунте для этого варианта выбирайте публичный репозиторий.

## Что работает

На Pages доступны все шесть этапов, иллюстрации, упражнения, таймер, Teacher Mode, сохранение локального прогресса и памятка для печати. Все разделы открываются внутри одной страницы: отдельные серверные маршруты и перенаправление 404 не нужны. Изображения встроены в компоненты SVG и не зависят от внешнего хостинга.

GitHub Pages публикует статический сайт и не запускает Node.js. Поэтому создание и подключение учебных комнат доступны в исходной серверной версии, но скрыты только в сборке Pages. Сервер `server.cjs` и прежний локальный запуск сохранены. Для синхронных комнат потребуется отдельный хостинг Node.js; нынешняя версия Pages рассчитана на демонстрацию экрана преподавателем.

## Сборка и защита данных

- В Vite режим `github-pages` задаёт base `/speak-up/` и отдельную папку `dist/github-pages`. Прежняя локальная сборка сохранена.
- Workflow устанавливает зависимости по `pnpm-lock.yaml`, проверяет TypeScript, собирает и публикует только `dist/github-pages`.
- `node_modules/`, `dist/`, `.runtime/`, `.env`, `.env.*` и журналы исключены из Git. `.gitignore` НЕ фильтрует ручную загрузку через браузер: используйте подготовленный чистый архив.
- В архиве нет зависимостей, готовых сборок, сохранённых комнат, токенов сессий и файлов окружения. Для публикации не нужны ваши API-ключи, пароли или Personal Access Token. Actions использует штатные разрешения GitHub.
- Локальные команды для разработчика: `pnpm run build:pages` — Pages; `pnpm run build` — прежняя сборка и самостоятельный HTML; `pnpm start` — сервер комнат.

Официальные инструкции: [Vite и GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages), [настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
