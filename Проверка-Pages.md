# Проверка подготовки GitHub Pages

Проверено 9 октября 2026 года.

- TypeScript: `tsc --noEmit` — успешно.
- Vite 7.1.9: сборка в режиме `github-pages` — успешно, base `/speak-up/`.
- Исходная локальная сборка и генерация `Открыть урок.html` — успешно.
- Chrome: статический сайт проверен по `http://127.0.0.1:4186/speak-up/`.
- Все 26 экранов шести этапов открываются; SVG-иллюстрации присутствуют, повреждённых изображений нет.
- Ошибок JavaScript и HTTP-ошибок ресурсов нет.
- Teacher Mode открывается; после перезагрузки выбранный раздел и прогресс сохраняются.
- В Pages нет запросов `/api/`, включая переход с параметром комнаты и сохранёнными старыми данными авторизации.
- Сервер комнат сохранён; его интерфейс доступен в обычной локальной версии.
- Чистый архив для GitHub не содержит node_modules, dist, .runtime, .env, журналов и сессионных данных.
- Workflow подготовлен, но реальный запуск Actions и публикация на GitHub ещё не выполнены: они начнутся после загрузки файлов и выбора Settings → Pages → GitHub Actions.

Локальный `pnpm run build:pages` столкнулся с ограничением Windows на создание символической ссылки в хранилище pnpm. Те же команды TypeScript и Vite были выполнены напрямую и завершились успешно. В Actions зависимости устанавливаются заново на Linux по существующему lockfile.
